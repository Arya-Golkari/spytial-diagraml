# DiagraML
This is a repository pertaining to my dissertation for Part II of the 
Computer Science Tripos at the University of Cambridge.

The complete title of my dissertation is "DiagraML: a programmatic diagramming 
library in OCaml", derived from Professor Anil Madhavapeddy's research idea 
page titled ["A programmatic diagramming library in OCaml"](https://anil.recoil.org/ideas/spytial-ocaml-port). 

Professor Madhavpeddy also serves as the day-to-day and marking supervisor for 
this project. Professor Shriram Krishnamurthi serves as a co-supervisor.

## Project proposal
Each dissertation begins with a [project proposal](https://www.cst.cam.ac.uk/teaching/part-ii/projects/project-proposal). 
Mine can be found, as a PDF, in `proposal/`. The LaTeX source files can be 
found in `proposal/src/`.
